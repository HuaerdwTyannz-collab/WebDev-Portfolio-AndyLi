🧠Design Thinking

Empathize

I thought about what visitors need to know about me. I wanted my website to be easy to read and simple to use.

Define

My goal was to create a portfolio that shows my introduction, hobbies, web development learning, and future interests.

Ideate

I chose a clean layout, simple colors, clear navigation, and short text. I did not want the website to look too busy.

Prototype and Test

I built the pages in VSCode and tested the links, images, and buttons in the browser.

Behind the Curtain

I used HTML for structure, CSS for styling, and JavaScript for simple interaction. The hardest part was making sure each file connected correctly.

I used browser preview and developer tools to check problems. I also tested my navigation links to make sure every page opened correctly.
